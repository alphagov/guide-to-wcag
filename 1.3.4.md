# 1.3.4 Orientation

## [WCAG says](https://www.w3.org/TR/WCAG21/#orientation):

> Content does not restrict its view and operation to a single display orientation, such as portrait or landscape, unless a specific display orientation is essential.

## When this is applicable

Always.

## Check if page is usable in different orientations

Use a mobile device that has a motion sensor to test in one orientation, then change the orientation and reload the page. If the page's orientation doesn't change when you rotate it, you might need to change your device settings so it's not locked to a specific orientation.

Check:

* content is readable and re-oriented
* functionality is usable
* you're not prompted to change the orientation

The page does not need to look the same or have exactly the same content when changing orientation.

## Exceptions

* if one particular orientation is essential, for example a piano application or slides for a projector
* if content is not necessarily restricted to landscape or portrait display orientation, for example virtual reality content

## Other ways to check

Use [BrowserStack](https://www.browserstack.com/) or similar services.

Do not use emulators or browser mobile view because you can get different results [depending on browsers and code](https://developer.mozilla.org/en-US/docs/Web/HTML/Viewport_meta_tag#viewport_width_and_screen_width).
