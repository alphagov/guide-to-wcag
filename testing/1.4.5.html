How to test for 1.4.5 Images of Text

WCAG says:

If the technologies being used can achieve the visual presentation, text is used to convey information rather than images of text except for the following:

  • Customizable: The image of text can be visually customized to the user’s requirements;

  • Essential: A particular presentation of text is essential to the information being conveyed.

When this is applicable

Always.

What are images of text?

Images of text are images that show text in place of actual text. This is sometimes done for stylistic reasons.

Images that are not primarily about the text are not classed as images of text, such as:

  • screenshots
  • diagrams
  • graphs
  • photos that include objects with text - like street signs
  • photos with overlaid, incidental text - like a watermark
  • symbolic text characters that represent an idea - for example a ‘B’ on a button for bold, or a key legend on a map

Check for images of text

Check:

  • there are no images of text - if there are, there must be text conveying the same information somewhere close

If unsure whether an element is an image of text, the most reliable way to check it is to inspect it in the code.

Text is unlikely to be an image of text when:

  • the text is found in the code between HTML tags (for example, <p>here is some text</p>)
  • it is selectable character by character, although some devices can select text within images
  • the text cannot be dragged in the same way as an image
  • the text can be adjusted in some way (for example, translation into another language)

Exceptions

  • logos, unless they are used for headings
  • inline SVGs using the text element, if it is marked up correctly
  • images that let the user customise the text

Best practice

  • Never use images of text, as it might not be clear to users that the text underneath says the same
  • If using an image of text is unavoidable, the text should be repeated immediately above or below it

Other ways to test

Use the Web Developer extension to disable images to find out what are images, but be aware this will not disable certain types of images such as background images and icon fonts.

Use the browser’s inspection tool to look at the code. See the ‘Other ways to test’ section for 1.1.1.
